# Sidra — Phase 0
Production foundation for Sidra, built from the Master Blueprint and revised Chapter 30. This phase includes the Next.js foundation, token system, Firebase client boundary, CMS-ready content registry, reusable layout primitives, cinematic opening, error/loading/empty states and CI quality gate.

## Local verification
1. Copy `.env.example` to `.env.local` and enter the existing Firebase Web App values.
2. `npm install`
3. `npm run check`
4. `npm run dev`

The page intentionally contains no fictional Studio or product data. Authentication and Firestore user profiles arrive in Phase 1. Domain schemas arrive in Phase 2.
