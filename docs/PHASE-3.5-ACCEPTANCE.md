# SIDRA Phase 3.5 Acceptance
- Discovery Pad is a standalone glass/canvas object with no search icon, keyboard icon, typed input, or placeholder text.
- Finger strokes are sent to the named Google Cloud Vision handwriting-recognition callable; there is no typed fallback.
- Only `active == true` and `approved == true` Studios can match or render.
- Exact calm no-match copy: `No verified artisan found.`
- Pinch listeners and `touch-action: none` are scoped to the Pad.
- Gallery contains no seeded, example, dummy, or fictional Studios.
- Canvas Engine is deterministic Canvas/MediaRecorder compositing only. No generative image/video endpoint exists.
- Product creation and product detail remain Phase 4/5.
